# ZARI 교수님 피드백 (2026-11-17)

리포트 지도 화면(3D 건물 + 위성 사진 + 건물 색)을 보고 받은 피드백이다.

## 순서

1. **다음 주(~2026-11-24)까지는 데이터 연결부터 한다.** 화면의 "예시" 값을 실제 데이터로 바꾼다.
2. 아래 디자인 피드백은 데이터 연결이 끝난 뒤에 반영한다.

## 디자인 피드백

| # | 피드백 | 해야 할 일 |
|---|---|---|
| 1 | 도로 레이어가 건물보다 위에 그려지는 느낌이 재밌다 | 이 효과는 지금처럼 유지한다 (좋은 반응) |
| 2 | 위치를 지도 안에서 직접 바꿀 수 있으면 좋겠다 | 지도에서 건물이나 지점을 눌러 "내 자리"를 옮긴다 |
| 3 | "빈 자리"보다 **"공실"** 이라는 말이 낫다 | 화면의 "빈 자리"를 모두 "공실"로 바꾼다 (지도 버튼, 범례, 설명 문구) |
| 4 | 가성비 공실 찾기는 시의적이다. "관리비만 내고 쓰세요" 같은 공실이 많다 | 공실을 서비스의 핵심 가치로 내세운다 |
| 5 | 공실을 상징하는 색을 정해야 한다 | **공실 = 오렌지**로 고정하고, 다른 곳에서는 오렌지를 쓰지 않는다 |
| 6 | 이 모드(건물 색으로 공실을 보는 지도)에서는 원이 더 크고, 지도가 움직이지 않아야 한다 | 원 크기를 키우고 끌기·확대를 막는다 |
| 7 | 처음부터 위성 사진이 나오지 않는 게 낫다. 켜고 끄는 스위치는 있는 게 좋다 | 기본값을 위성 사진 꺼짐으로 바꾸고 스위치는 남긴다 |
| 8 | 왜 어둡게 했는지는 알겠지만 너무 어둡다 | 다른 건물을 밝게 해서 카페·공실·내 자리와 잘 구별되게 한다 |
| 9 | 내 예산을 고를 수 있으면 좋겠다 | 예산(보증금·월세 등)을 입력하거나 고르게 하고, 그 안에 드는 공실만 보여 준다 |

* 6번의 "이 모드"는 건물 색 지도를 말한 것으로 이해했다. 다른 모드였다면 이 줄을 고친다.

## 데이터 연결 대상 (지금 "예시"로 표시된 칸)

- 등급(B+), 추정 월매출, 창업 비용과 회수 기간, GOOD·WATCH 인사이트: `src/demo.js`
- 유동인구 층과 시간대별 사람 수: `src/LineMap.jsx`
- 가게별 추정 월매출 카드: `src/LineMap.jsx`
- 비교함의 예시 후보 2곳: `src/demo.js`
- 출처 계획: 서울 열린데이터광장 상권분석(추정매출·유동인구·상주·직장 인구·집객 시설·상권 변화, 분기 갱신). 임대료·권리금·가게별 매출은 민간 데이터라 예시로 남을 수 있다.
- 9번 예산 필터를 하려면 **공실 데이터에 임대 조건(보증금·월세·관리비)이 있어야 한다.** 데이터를 고를 때 함께 확인한다.

## 함께 걸려 있는 결정

- 지도 버튼 줄 모양: A~D안 중 고르는 중이다(추천 B안, 밑줄 글자). 실제 사이트에서 `?view=report&lv=b`처럼 붙이면 각 안을 볼 수 있다.
- 3·7번을 반영하면 지도 버튼 이름과 기본값도 함께 바뀐다.
